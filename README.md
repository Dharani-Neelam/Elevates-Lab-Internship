# Elevates-Lab-Internship
Internship-Task-1

Task 1 - Basic Calculations

As part of my internship at Elevates Lab, the first task is to build a simple program that performs basic mathematical calculations.
The goal of this task is to strengthen understanding of fundamental programming concepts such as:
-Taking user input.
-Performing arithmetic operations (Addition, Subtraction, Multiplication, Division).
-Displaying results in a clear and user-friendly format.
-Writing clean, structured, and reusable code.
Features:
-Supports all basic arithmetic operations.
-Handles invalid input gracefully.
-Beginner-friendly implementation.
